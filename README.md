## Featured Projects

### 1. Vortex — Local-First Desktop Workbench

**Electron · Desktop Application Development · SEO Tooling · Automation**

A cross-platform, local-first desktop application built with Electron, designed for engineers, technical SEOs, analysts, and power users. Vortex combines developer utilities, SEO auditing, web scraping, networking tools, workflow automation, and media processing in a unified desktop environment.

**Core Modules:**

- **CrawlDeck:** Static and dynamic web scraping, DOM inspection, schema detection, and multi-format data export.
- **RankPulse:** SEO auditing, SERP previews, structured data validation, broken-link analysis, and AI/LLM readiness checks.
- **DevStation:** Network diagnostics, port scanning, DNS lookups, SSL/TLS inspection, JWT debugging, security tools, and developer utilities.
- **Visual Workflows:** Node-based pipelines for downloading, filtering, converting, compressing, and organizing files.
- **Universal Download Manager:** Multi-connection downloads, BitTorrent support, playlist downloads, and Chrome/Edge browser extension.
- **OmniDrop:** Wireless LAN file transfers with QR-based access and PIN protection.
- **Media & Data Utilities:** CSV processing, batch renaming, media conversion, FFmpeg compression, metadata editing, and duplicate detection.
- **Cross-Platform Distribution:** Windows installers, portable executables, and Linux packages with release-based updates.

**Downloads:** Windows 10/11 · Windows Portable · Linux AppImage · Debian Packages
